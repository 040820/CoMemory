# 开放状态语义归一化

## 范围与启用

`state_semantic_normalization: True` 启用开放语义阶段。两个 Event–State 配置已开启；Config 默认关闭，以保留旧实验及直接调用的协议。它处理上层 state 候选，不改写 Chunk、原始 Triple 或 MultiDiGraph 边，也不把普通历史活动强行转成状态。

本轮按用户要求只修改代码和说明，没有运行测试、LLM 调用或数据集重建。效果尚需后续实验确认，不能据此声称所有同义表达都能正确识别。

## 不依赖领域白名单的流程

1. 先对原始候选执行原文引用、主体归属及 Triple 来源检查。
2. 用主体索引、原始关系与 BGE-M3 召回少量历史 state Fact；历史 event 不参与状态对齐。
3. LLM 根据新证据和少量历史槽描述，给出开放 dimension、作用域 scope、语义值 value、基数及事实模态。维度和取值不设置“牛奶过敏”等专门列表。
4. 若与某个历史槽同维度、同对象/范围、同模态，复用历史槽及值命名；同义值归到同一标签。作用域的每个值仍须出现在当前引文中，不能靠共享主体或名称相似合并。
5. 再按规范槽召回候选。需要 REPLACE/CORRECT 时，独立调用证据门控，重新判断同槽、互斥、变化/纠正证据及时间一致性。归一化器的结论不会自动当作更新证据。
6. 保留事实、决策、证据和归一化依据；不确定的归一化留出明确原因，原始候选按原有保守规则处理。

例如“已开启/已经打开”“已关闭/不再开启”可以分别形成同义值；不同设备不能合槽。项目阶段、团体成员身份、偏好、访问权限等也使用同一套接口。多值集合继续并存，不能因新值不同就替换。

## 原始内容与比较表示分开

以下仅为字段示意，没有执行模型：

```text
原文：客厅灯现在已经关闭。
source_attribute = turned_off       原始抽取谓词
source_value = 客厅灯               原始对象
source_scope = {}                  原始抽取范围
source_modality = actual            原始抽取模态

attribute = power_status           开放的规范维度，由模型结合证据提出
scope = {device: 客厅灯}            作用对象
modality = actual                  已确认事实的模态
value = 客厅灯                     保留旧接口的原始值
semantic_state.value = off         用于比较的语义值
semantic_state.cardinality = single
semantic_state.evidence_quote = 客厅灯现在已经关闭。
```

`semantic_state.value` 是派生的比较标签，不要求逐字出现在原文；原始 value、quote 与来源引用已在前一阶段核对，仍然保留。`validated` 仅表示程序通过结构和来源检查，不表示语义判断已经获得人工真值验证。

同一对象某状态“不成立”可以仍是 actual，否定体现在语义值中；计划和假设不可因此升级成已发生事实。多值集合的新增成员仍执行 ADD；同一个槽的基数判断冲突会进入 UNCERTAIN。

同义归一化后相同值可以 NOOP；不同值不会因为文字包含关系而自动 REFINE，需要独立的变化门控。当前状态的回答上下文和变化记录使用语义值，并同时保留原始值用于追溯，避免出现“对象 → 同一对象”这种无法说明状态变化的展示。

## 持久化与版本

- Fact 新增 `semantic_state`、`semantic_normalization` 及 source_* 原始字段。
- `current/members` 仍按主体、规范维度、scope、modality 建索引。
- 决策保存归一化依据、新引文和 Triple 来源；变化边保存规范 old/new 状态及原始 old/new 值。
- 归一化开启时使用写入协议 v3；关闭时仍是 v2。已有非空上层不能跨协议追加。
- 若已有中层的 extracted Triple 完整，可以使用独立输出目录重建上层，无需为此重新抽取中层。
- `llm_trace.jsonl` 中归一化调用的 stage 为 normalize；每个 state 候选增加一次 LLM 归一化调用，后续更新门控另计。

## 泛化的边界

开放命名不等于语义判断必然正确。候选召回、主体/对象的别名对齐、原文歧义和基数判断仍会影响结果。当前范围值须有明确引文锚点；缺少共同对象证据的代词或别名不强行归并。不确定时宁可保留原始事实或交待核查，也不把正反词面关系直接当成状态变化。
