# LoCoMo 上层写入修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 提高真实 LoCoMo 对话中可追溯事件与状态的写入质量，同时保持原图和旧实验结果可审计。

**Architecture:** 抽取阶段限制输出量并记录失败；校验阶段按原文片段和事实类型门控；原始 Triple 逐 Chunk 保存；时间解析区分精确日期与范围。所有修复均使用新结果目录验证。

**Tech Stack:** Python、NetworkX、vLLM OpenAI 接口、现有 EventStateLayer。

**Spec:** 用户 2026-10-26 的《LiCoMemory 上层 Event–State 写入问题排查与修复》。

## Global Constraints

- 不取消原文引用、主体归属和 Triple 来源校验。
- 不改写已完成的 sample0 原始图及运行结果。
- 用户现有未提交修改保留；提交时只纳入已核查的相关文件。
- 不以产生 REPLACE/CORRECT 数量为修复目标，必须由原文支持。

## Review Focus

- 模型遗漏 quote 或输出截断时，应重试或留下明确失败原因，不能写入无证据事实。
- 同一主体的不同活动与重复对话行为不能合并成同一现实事件。
- 无原始 Triple 的旧图只能标记为部分恢复，不能标成完整来源。
- 相对时间与模糊区间不得伪装为单日事件时间。
- 地点等事件属性必须与对应活动出现在同一证据片段并通过类型校验。
