# 固定事实对的证据解释实验计划

**目标：** 固定新旧 Fact 两端，分别检查证据是否找到、关系是否判对、原文引用是否准确。

**范围：** 复用现有三层存储和双端 Judge，以独立小样本探针建立基线；不做自动覆盖，不改已有实验产物。先用图扩展，再依据错误类型评估 PPR。置信度融合不在本轮引入。

**实验设计：** 重复、并存、明确变化、明确纠正、不同作用域，以及同一预约日期事实对在“改期”“原通知误读”“缺少解释”三种条件下的判断。期望关系先于模型运行固定，标签由本实验设计给定，未经过独立人工标注验证。

- [x] 冻结受控输入、参考标签、原文证据和干扰项；检查配对样本两端完全相同。

- [x] 分别统计最终关系、状态、解释证据是否被检索/实际展示/正确引用，不能把三者混成一个指标。
